# Инструкция для ревью кода

## Цель

Проведи ревью `app.js`, `index.html`, `style.css` по правилам чистого кода и запиши отчёт. Файлы не редактируй: только анализируй и объясняй.

## Границы

Проверяй пять категорий: мёртвый код; дублирование обработчиков и логики; имена, непонятные без комментариев; комментарии, пересказывающие код; функции, которые не читаются целиком.

Не трогай: остальные файлы; то, что исправляют ESLint и Prettier. Исправления не должны нарушать чек-лист поведения из `README.md`.

## Критерий готовности

Все три файла прочитаны целиком, по каждой категории есть замечания или «Замечаний нет», изменён только `review-report.md`.

## Формат вывода

Файл `review-report.md` на русском, замечания сгруппированы по пяти категориям. Каждое замечание с пометкой «обязательно» или «желательно» состоит из четырёх частей:

- Место: `app.js:45`, функция `editTask`
- Проблема: что не так
- Условие: когда проявляется
- Как проверить: действие с наблюдаемым результатом
